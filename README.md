## Features

| Feature | Description |
|---------|-------------|
| 💰 **Multi-Currency Support** | Calculate loans in USD, EUR, GBP, RUB, JPY and more. |
| 📊 **Annuity & Differentiated** | Switch between annuity and differentiated repayment schedules. |
| 📅 **Flexible Loan Terms** | Enter duration in months or years with automatic conversion. |
| 📈 **Dynamic Rate Input** | Support for annual, monthly, or daily interest rates. |
| 💵 **Down Payment & Fees** | Factor in initial payments and additional fees instantly. |
| 🗓️ **Payment Schedule** | Detailed month-by-month breakdown of principal, interest, and balance. |
| ⚡ **Real-Time Calculation** | All values update instantly as you type — no page reloads. |
| 📱 **Fully Responsive** | Optimized for desktop, tablet, and mobile screens. |

## Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- No server or build tools required — runs entirely client-side

---

## Usage

### 1️⃣ Open the Calculator
Simply open `index.html` in your browser — no installation needed.

### 2️⃣ Enter Loan Details
- **Loan Amount** — Total sum you wish to borrow
- **Down Payment** — Upfront payment to reduce the principal
- **Loan Term** — Duration in months or years
- **Interest Rate** — Annual, monthly, or daily percentage
- **Additional Fees** — Extra costs added to the loan

### 3️⃣ Choose Payment Type
Select **Annuity** for fixed monthly payments or **Differentiated** for decreasing payments over time.

### 4️⃣ View Results
Instantly see your monthly payment, total cost, and overpayment amount.

### 5️⃣ Explore Payment Schedule
Click **Show Payment Schedule** to reveal a detailed table with principal, interest, and remaining balance for every period.
